# 🖼️ Image Restoration using OpenCV Inpainting

This project demonstrates how to restore a **damaged photograph** using **OpenCV's Inpainting algorithm** in Python.  
Image inpainting is a computer vision technique used to reconstruct missing or damaged parts of an image by analyzing surrounding pixels.

It’s commonly used in:
- Old photo restoration
- Object removal
- Scratch & spot removal
- Image editing applications

---

## 📌 Project Overview

In this project, we:

1. Load a damaged image  
2. Detect damaged regions using thresholding  
3. Create a mask for the damaged areas  
4. Improve mask coverage using dilation  
5. Restore the image using OpenCV's **TELEA inpainting method**  
6. Visualize each processing step
